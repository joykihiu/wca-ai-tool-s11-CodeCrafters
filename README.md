# wca-ai-tool-s11-CodeCrafters
## Nuru Customer Feedback AI Tool

This project uses Google's Gemini API to analyze customer feedback for Nuru products and generate useful business recommendations.

## Features
ssss
- Analyzes customer sentiment
- Identifies the relevant Nuru product line
- Determines the urgency of customer feedback
- Generates recommended actions and customer replies
- Supports individual customer feedback
- Supports batch testing using `sample_feedback.txt`
